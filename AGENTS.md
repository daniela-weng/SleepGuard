# Codex Wearable Project

An AI-driven wearable + companion app concept for monitoring breathing/sleep patterns in seniors with sleep apnea. This file is a short index — see the linked docs for the actual detail:

- [project-brief.md](project-brief.md) — goal, target user, pain points, design principles
- [technical-setup.md](technical-setup.md) — platform, file map, run/setup instructions

- [iteration-progress.md](iteration-progress.md) — history of major design/build iterations, in order

## At a glance
- **Platform:** React web app only (`Web App/SleepGuard/`) — the earlier iOS/SwiftUI track has been dropped.
- **Active screen:** variant **H** (`components/morning/MorningSummarySunrise.tsx`). J/K are older explorations, M is a mascot gallery.
- **Status:** design exploration / mockup — not wired to a real device or backend.
