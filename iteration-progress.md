# Iteration Progress

A running log of what changed each version and why, in order — including which earlier versions were deliberately kept around for comparison rather than deleted. **H is the current main version; J and K are earlier explorations kept alongside it for comparison, not maintained in lockstep.** Useful for understanding *why* something looks the way it does, not just what it currently looks like.

1. **Initial mockup** — React + Tailwind iPhone frame (402×874), 16pt+ text, large tap targets for 65+ users.
2. **Feature sprawl, then scoped back** — added Treatment tab, Settings tab (Fitbit connect, biometric toggles, caregiver SMS digest, emergency call), and a floating AI chat/voice widget. Later scoped down to a single-screen "Morning Summary" exploration; the tabbed-app files became the orphaned files listed in `technical-setup.md`.
3. **Variant exploration** — 6 "Today" layouts (A–F), then 3 "Morning Summary" layouts (G/H/I) built with shadcn/ui after locking that in as the standing component library.
4. **H locked in as primary** — heavy iteration on color, font pairing (settled on Sora + Manrope), corner radius (4px), spacing (4px grid), and a Blue (`#4f7ea3`) + Amber palette, with contrast fixes verified via computed-luminance math along the way.
5. **Content rebuild around real AHI data** — Normal/Mild/Moderate/Severe severity bands, severity-conditional alerting, reversing an earlier "no AHI" constraint once explicitly re-scoped.
6. **Major restructure** — per-day mini-rings instead of buttons, "Good morning, Celena!" greeting, bad-to-good sleep rating, Week/Month toggle, plus two new alternate layouts (J inspired by a calorie-tracking app, K inspired by a doctor-finder app).
7. **Continued H polish** — full-bleed blue header, sticky CTA, month view gets a 3rd severity color (gold/moderate), white background, month-view "Doctor's Notes" style trends card.
8. **Mascot system** — 5 concepts (Wink, Sunny, Breezy, Luna, Pip) rendered as SVGs, then given mood-reactive expressions/animations (Great/Good/Okay/Worried) with idle CSS animations and a `prefers-reduced-motion` guard. Wink/Luna/Pip later got more detailed illustrated variants; Luna's face was rebuilt twice (fixed asymmetric eyes, then simplified to a fixed beak-as-mouth design) based on direct feedback.
9. **Landing page refinement** — dropped explicit "AHI" jargon in favor of plain language, enforced a hard no-scroll constraint on the phone-frame viewport, added per-day rating scores inside the day circles, combined the headline/summary into two left-aligned lines, added a "See details" entry point, added a "Doctor's Notes" clinical-language toggle to the month view.
10. **Sleep Details drill-down built** — 3 tabs (Breathing, Oxygen Level, Sleep Quality), each with its own stats and chart (breathing-rate trace, SpO₂ trace with a 90% reference line, sleep-stage hypnogram + proportional bars), plus a persistent "Questions for Your Doctor" note-taking card.
11. **Design-system spec pass, then reverted** — explored a more elaborate pill-shaped button/toggle system (shadcn Button, specific padding/shadow/font-size rules) at the user's request, then fully scratched it back to the prior amber/toggle look at their follow-up request. The card-stroke and font-size fixes from the WCAG pass (step 12) were layered on top of the *reverted* state, not the scratched pill system.
12. **WCAG AA accessibility pass** — measured actual rendered contrast (canvas-resolved colors, not assumptions) across every screen, found and fixed: header text contrast, opacity-reduced captions, a near-invisible white-on-light-blue label in the sleep-stage bars, and non-keyboard-accessible month-view dots (hover-only tooltips on non-focusable elements).
13. **Platform decision** — dropped the iOS/SwiftUI track; the React web app is now the only actively maintained platform.
14. **Shape-system update** — standardized the actively maintained React app's rectangular surfaces and controls to a 12px corner radius, and updated both design-system references to match. Circular controls and icons remain circular by design.
